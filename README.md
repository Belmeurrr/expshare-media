# expshare-media

Images for Exp. Share social media posts (Instagram @EXP_Share_tcg, X @EXPshareINC).

This repo is public on purpose: Buffer, the scheduler that publishes the posts, only accepts images
from a public link that does not expire, so each post image is linked from here as a
`raw.githubusercontent.com` URL.

- `posts/` — one image per post, named `YYYY-MM-DD-<slug>.png`, exported from Canva.
- Only finished, approved post images belong here. Never commit drafts, customer data or anything
  that is not meant to be public.
